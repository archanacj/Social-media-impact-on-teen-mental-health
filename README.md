# Social-media-impact-on-teen-mental-health

Social Media Impact on Teen Mental Health – Power BI Dashboard
A mini project built with Excel and Power BI to explore how teens' social media use relates to their sleep, stress, anxiety and depression.

Tools Used
Microsoft Excel (data preparation)
Power BI Desktop (dashboard and DAX measures)
Dataset
Two tables: Student Info (gender, age group, platform, usage category, social media hours, screen time before sleep, sleep hours, physical activity) and Mental Health (anxiety, stress, depression, total mental health score, risk level).

Dashboard Pages
1. Overview Dashboard

KPI cards: Total Students, Average Sleep Hours, Average Anxiety, Average Stress
Social media hours vs anxiety level
Usage category by gender
Platform usage distribution
Average sleep hours by gender
Stress level vs screen time before sleep
2. Detailed Analysis

Sleep hours vs social media hours (scatter)
Usage category by risk level (funnel)
Students by stress level (treemap)
Mental health score by physical activity (area)
Age group summary table
Filters: Gender, Age Group, Platform Usage, Usage Category
